* LEX-0002: Homoglyph Smart Quote Confused

* LEX-0003: Unterminated String Literal
* Represents: A string literal that reaches the end of a line (\n) or the end of the file without a closing quote character.
* LEX-0004: Malformed Numerical Constant
* Represents: A numeric constant containing invalid suffix characters or multiple radix points (e.g., 3.14.15 or 42z).
* LEX-0005: Invalid Escape Sequence

## Syntactic & Structural Errors (SYN-1001 to SYN-1999)
These errors occur during parsing when the tokens themselves are valid, but they are arranged in an illegal grammatical order.

* SYN-1001: Missing Statement Terminator
* Represents: A missing semicolon ; at the end of a statement, or a missing comma inside a structural argument block.
* SYN-1002: Unmatched Scope Delimiter
* Represents: A closing bracket, parenthesis, or curly brace (}, ], )) that has no matching opening counterpart earlier in the stream.
* SYN-1003: Expected Identifier
* Represents: A keyword or type declaration is placed where a variable name or function identifier is required (e.g., int default = 5;).
* SYN-1004: Empty Conditional Body
* Represents: An structural block like if, while, or for that expects an expression or block body but instead runs directly into an illegal terminator.
* SYN-1005: Dangling Multi-declaration
* Represents: Trying to declare multiple variables separated by commas but failing to provide a terminal name or value (e.g., int x, y, ;).
